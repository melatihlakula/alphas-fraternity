# ⚠️ IMPORTANT: How to Access Your Website

## 🔴 The Problem

You're getting "check your connection" errors because you're opening the HTML file directly instead of through the server.

## ✅ The Solution

### You MUST access the website through the server URL:

**Open your browser and type this EXACT URL:**
```
http://localhost:3000
```

### ❌ DO NOT:
- Open the HTML file directly (double-clicking index.html)
- Use file:// URLs
- Open from Finder

### ✅ DO THIS:
1. Make sure server is running (check your terminal)
2. Open your web browser
3. Type: `http://localhost:3000`
4. Press Enter

## 🎯 Quick Steps

1. **Check server is running:**
   - Look at your terminal
   - You should see: "🚀 ALPHAS Fraternity server running on http://localhost:3000"

2. **Open browser:**
   - Open Safari, Chrome, or Firefox
   - Click the address bar
   - Type: `localhost:3000`
   - Press Enter

3. **Verify:**
   - The URL bar should show: `http://localhost:3000`
   - NOT `file:///Users/...`
   - Navigation links should work
   - Contact form should work
