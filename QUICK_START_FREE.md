# 🆓 FREE Deployment - Super Quick Guide

## ⚡ 3 Steps to Go Live (FREE!)

### 1️⃣ Sign Up at Railway
- Go to: https://railway.app
- Click "Start a New Project"
- Sign up with GitHub (free, no credit card)

### 2️⃣ Deploy Your Code
- Click "New Project" → "Empty Project"
- Click "Deploy from local directory"
- Upload your project folder
- Wait 2 minutes for deployment

### 3️⃣ Add Environment Variables
In Railway dashboard → Variables tab, add:

```
NODE_ENV=production
OWNER_EMAIL=hlakulaachuma@icloud.com
OWNER_PHONE=+27655642698
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-gmail-app-password
FROM_EMAIL=your-email@gmail.com
```

### ✅ Get Your Free URL
- Railway gives you: `https://yourproject.railway.app`
- **That's your live website!** Share it!

## 📧 Free Gmail Setup (2 minutes)

1. Google Account → Security → 2-Step Verification (enable)
2. App passwords → Create → Select "Mail"
3. Copy password → Use as `SMTP_PASS` above
